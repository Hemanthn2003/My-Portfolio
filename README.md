## 📌 Description

This is a **modern developer portfolio website** built using React and Vite, designed to showcase my projects, skills, and experience in an interactive and visually appealing way.

The portfolio includes smooth animations, project demos with video previews, responsive design, and a clean UI. It highlights my work in full-stack development, including real-world applications and creative web solutions.

* 🎬 **Project Showcase with Video Demos**

## 👌 Quick Start

### Prerequisites

* Node.js
* Git

### Run Locally

```bash
git clone https://github.com/Hemanthn2003/My-Portfolio.git
cd My-Portfolio
npm install
npm run dev
```

👉 App runs on: [http://localhost:5173](http://localhost:5173)

## ☁️ Deployment

### Vercel Deployment

1. Push code to GitHub
2. Go to [https://vercel.com](https://vercel.com)
3. Import your repo
4. Click **Deploy**
